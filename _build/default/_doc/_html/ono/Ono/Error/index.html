Module Ono.Error

Error type for the ono runtime.

Covers the message-based `Msg errors raised by ono itself and the Wasm-level traps surfaced by Owi (unreachable, division by zero, …).

type t = [
  1. | `Msg of string
  2. | `Call_stack_exhausted
  3. | `Conversion_to_integer
  4. | `Integer_divide_by_zero
  5. | `Integer_overflow
  6. | `Out_of_bounds_memory_access
  7. | `Unreachable
]

All error tags ono can produce. Each non-`Msg tag corresponds to a Wasm trap and is mapped to a dedicated process exit code by the CLI layer.
