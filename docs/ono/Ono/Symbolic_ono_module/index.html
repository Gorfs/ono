Module Ono.Symbolic_ono_module

Symbolic ono runtime module.

Provides the externs exposed to a Wasm program under symbolic execution: print_i32, fresh symbolic i32 values, and a (concrete) stdin reader.

This module is linked against the user program under the name "ono".
